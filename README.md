# git

`D:\git-repo` 本地仓库，已关联 GitHub 远端。

> 注意：`D:\git` 是 **Git 安装目录**（`D:\git\Git\`），不是本项目目录，请勿混淆。

## 远端

- 仓库地址：<https://github.com/RONGYAOSB/git>
- 认证方式：SSH（ed25519，密钥 `~/.ssh/id_ed25519_github`）

## 常用命令

```bash
git status          # 查看改动
git add -A          # 暂存全部
git commit -m "msg" # 提交
git push            # 推送到 GitHub
git pull            # 拉取远端
```
